LXMSTR apt repository

Real-time EtherCAT master — latest release: v1.0.1

Install

curl -fsSL https://lynx-technologies-llc.github.io/lxmstr-apt/lxmstr.gpg | sudo tee /usr/share/keyrings/lxmstr.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/lxmstr.gpg] https://lynx-technologies-llc.github.io/lxmstr-apt stable main" | sudo tee /etc/apt/sources.list.d/lxmstr.list
sudo apt update && sudo apt install lxmstr

Supported distributions

Packages are built against glibc 2.35 (Ubuntu 22.04 baseline) with GCC 12, for amd64 and arm64. glibc is backward compatible, so any distro at or above this baseline works.
